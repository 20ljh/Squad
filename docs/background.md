# 기획 배경과 결정 기록

개발 중 "왜 이렇게 정했지?"가 궁금할 때 보는 문서입니다. 개발 규칙은 루트 `CLAUDE.md`에 있습니다.

## 주제를 정한 과정

- 2026학년도 1학기 단국대 소프트웨어학과 졸업작품(약 13팀)과 GitHub 저장소를 먼저 훑어 평균적인 범위와 난이도를 확인했다.
- 새 주제의 조건: 게임이 아닐 것, AI를 쓰더라도 비용이 크지 않을 것, 학교가 주는 학습용 클라우드로 배포할 수 있을 것.
- 탈락한 후보: 금융·송금 서비스(토스와 겹침), 민원 서비스(국민신문고와 겹치고 법적 고려사항이 많음), 초중고 학습 보조(대학 졸업작품으로는 수준이 낮아 보임).
- 학생들이 매주 겪는 "회의 끝나고 누가 정리하지?" 문제로 정했다.

## Notion과 겹치지 않는 이유

Notion에도 AI 회의록(AI Meeting Notes)이 있지만, 조사 당시 기준으로:
- Business 플랜 이상(1인당 월 $20)에서만 쓸 수 있고
- 데스크톱 앱 전용이며
- 한국어 회의에서는 화자를 구분하지 못한다.

그래서 무료·학생용 도구로 따로 만들고, 결과는 Notion "안으로" 내보내는 보완재로 자리 잡았다. Notion 연동은 무료 플랜에서도 되는 Internal Integration 토큰 방식으로 한다.

## 경쟁 서비스에서 가져온 아이디어

| 기능 | 참고한 서비스 |
|---|---|
| 팀원별 발언 비율·액션아이템 완료율·출석 | Fellow |
| 회차별 발언 비율 추이 | MeetGeek |
| 하이라이트 인용구 | tl;dv, Grain |
| 회의록 열람(캐치업) 현황 | Fellow |
| 지난 회의 자연어 검색 | 여러 서비스의 공통 기능 |
| 팀 용어 사전으로 오인식 보정 (Phase 3) | 티로 (맥락 기반 용어 보정) |
| 캘린더·Slack 원클릭 연동 (Phase 3) | 콜라보 |

국산 서비스 중 티로(기록 정확도·다국어·로컬 보관)와 콜라보(화상회의 연동·Notion 등 협업툴 연동·엔터프라이즈 보안)는 둘 다 유료·기업 지향이다. 우리는 무료, 학생 팀, 회의 흐름 시각화, 팀 참여도 분석에 집중한다.

## 화면

- 결과 화면 2개(회의 결과, 팀 대시보드)를 먼저 디자인했다. 입력 화면과 메인 화면은 아직 설계 전.
- 스타일은 Soft UI(파스텔 + 둥근 형태 + 부드러운 그림자 + 은은한 입체감). 참고 이미지에서는 방향만 가져왔고, 색상 값은 새로 정해 글자 대비를 계산해 맞췄다(참고 이미지와 같은 색은 없음).
- 처음 목업은 차분한 초록 계열 문서형 UI였고, Soft UI로 바꾼 뒤 지금의 바이올렛 톤이 됐다.

## 이름

처음엔 가칭 "모임로그"로 진행하다가, 2026-11에 서비스 이름을 "Squad"로 최종 확정했다. 이름은 `apps/web/lib/brand.ts`의 `BRAND.name`에서 관리한다.
